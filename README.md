# VTUBER-SKIN-REPO
Isi repo skin untuk app VTUBER CHARACTER FLOAT: `skins/<id>/{skin.svg,skin.json,preview.png}` + `index.json`.
Alat pembuat ada di proyek VTUBER-FLOAT (`tools/`). Perbarui indeks: `python3 ../VTUBER-FLOAT/tools/make_index.py ../VTUBER-SKIN-REPO`
Skin: `mommy` (cewek rambut cokelat), `mash` (cowok rambut mangkuk, tangan+roti menutup mulut).
